# ScreenWeave WordPress Platform

ScreenWeave managed WordPress mu-plugin for production defaults, health checks, staging/holding behaviour, SMTP configuration, and security hardening.

This plugin is intended to be installed by `sw-wp-site-template` through `platform/plugins.manifest`.

## Install manifest entry

```text
github|mu-plugin|screenweave-platform|ScreenweaveNZ/sw-wp-platform|v1.0.0|screenweave-platform.php
```

Use pinned tags or SHAs for production deployments.
